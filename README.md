# HdR Pass — Demo Interactivo

Prototipo de alta fidelidad para la app móvil **HdR Pass**, la tarjeta prepago de fidelización de Hijos de Rivera.

## ¿Qué es?

Demo navegable con 6 pantallas: Bienvenida, Suscripción, Activación, Dashboard, Detalle de gastos y Pago en HORECA. Todos los datos son ficticios y el archivo es completamente autocontenido (imágenes embebidas en base64).

## Cómo abrirlo

**Online:** [https://JAM8913.github.io/hdr-pass/](https://JAM8913.github.io/hdr-pass/)

**Local:** descarga `index.html` y ábrelo directamente en el navegador — no necesita servidor ni conexión a internet.
